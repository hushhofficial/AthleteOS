# AthleteOS – Personal Performance & Recovery AI

A clean web dashboard for tracking athletic performance, body composition, recovery, and getting AI-style insights.

Built for sprinter / power athletes.

## Features

- **Dashboard**: Weight, skeletal muscle, body fat, resting HR, recent activity, recovery snapshot
- **Log Entry**: Easy logging for runs, intervals, strength, sleep quality, how you feel
- **History**: Full training history + export to JSON
- **AI Insights**: Automatic analysis of volume, recovery trends, RHR, and goal recommendations
- **Goals**: 1 km target tracking + athlete profile

## Athlete Profile (default)

- Age: 17.5
- Height: 176 cm
- Goal: 1 km in 5:30–5:40
- Training venue: Satyabrata Stadium, Cuttack (soft soil/clay track)

## How to use

1. Open `index.html` in any modern browser (or serve the folder)
2. Go to **Log Entry** and add your sessions
3. Data is saved locally in your browser (localStorage)
4. Check **AI Insights** after a few logs
